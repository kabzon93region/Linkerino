# План реализации Linkerino

> **Для исполнителя:** шаги отмечены чекбоксами; план реализуется в этой же сессии.

**Цель:** переносимый `Linkerino.exe` (Win32, C++17, статический CRT) переносит выбранную папку и заменяет её настоящей символьной ссылкой каталога, не теряя данные ни на одном сбое.

**Архитектура:** `win_util` — пути, тома, логирование; `engine` — проверка плана, снимок дерева, копирование в staging, сверка, публикация, подмена ссылкой, удаление резерва с повторной проверкой; `main_win32` — окно и рабочий поток. Перенос идёт в отдельном потоке, интерфейс только показывает прогресс и просит отмену.

**Стек:** C++17, Win32, CMake, VS2019 Build Tools, x86, `/MT`, `_WIN32_WINNT=0x0601`, подсистема 6.01.

**Спецификация:** [2026-11-24-linkerino-design.md](../specs/2026-11-24-linkerino-design.md)

## Общие ограничения

- Без .NET, инсталлятора и внешних DLL; один EXE.
- Поддержка только локальных томов NTFS; сеть, EFS, жёсткие ссылки, точки повторной обработки, каталоговые потоки — отказ до удаления.
- Оригинал удаляется только после: полной сверки, устойчивой записи копии, публикации под именем, создания и проверки ссылки, повторной проверки каждого элемента.
- Отмена разрешена только до публикации; окно не блокируется.
- Данные пользователя (`C:\atiflash`, `B:\BKP`) не используются в тестах.

## Задачи

### Задача 1: Каркас проекта и общие утилиты

**Файлы:** `CMakeLists.txt`, `src/win_util.h`, `src/win_util.cpp`, `.gitignore`, `AGENTS.md`

- [x] Канонизация пути через `GetFinalPathNameByHandleW`, сравнение без учёта регистра (`CompareStringOrdinal`), проверка вложенности.
- [x] Проверка тома: локальный, NTFS; `CreateSymbolicLinkW` с флагом непрошеного режима только на Windows 10 1703+ (реальная версия через `RtlGetVersion`).
- [x] Лог `Linkerino.log` рядом с EXE (или в `%LOCALAPPDATA%\Linkerino`).
- **Проверка:** конфигурация CMake и сборка пустого каркаса без предупреждений `/W4`.

### Задача 2: Снимок дерева и копирование

**Файлы:** `src/engine.cpp`

- [x] Скан: относительные пути в pre-order, идентификатор файла, размер, даты, атрибуты, сигнатура DACL, именованные потоки.
- [x] Отказ при точках повторной обработки, EFS, облачных заглушках, жёстких ссылках, потоках на каталогах.
- [x] Копирование в `B:\<parent>\.linkerino-stage-<guid>`: данные, потоки, DACL, даты, атрибуты; `FlushFileBuffers` после каждого файла; SHA-256 по ходу чтения.
- **Проверка:** юнит-сценарии переноса обычного дерева, кириллицы, пустых каталогов, потока `Zone.Identifier`.

### Задача 3: Сверка и публикация

**Файлы:** `src/engine.cpp`

- [x] Проверка staging по снимку: набор путей, типы, размеры, даты, DACL, хэши данных и потоков; отсутствие лишних объектов.
- [x] Повторная проверка неизменности источника (идентификатор, размер, дата изменения).
- [x] `MoveFileExW` staging → итоговое имя без перезаписи; запись журнала с путями и серийным номером тома.
- **Проверка:** тест «подмена после сверки» — публикации нет, оригинал цел, staging удалён.

### Задача 4: Ссылка, удаление резерва, журнал

**Файлы:** `src/engine.cpp`

- [x] Переименование источника в `.linkerino-backup-<guid>`, `CreateSymbolicLinkW`, проверка тега reparse и совпадения итогового пути/идентификатора каталога.
- [x] При неудаче — восстановление исходного имени, копия остаётся, пути показаны пользователю.
- [x] Удаление резерва в обратном порядке с повторной проверкой идентификатора, размера, дат и хэша каждого файла; при расхождении остановка и сохранение остатка.
- [x] Журнал: состояния `copying`/`verified`/`published`/`linked`, устойчивая запись; при следующем запуске только сообщение, без автоудаления.
- **Проверка:** тесты отказа ссылки, отмены, конфликтов и восстановления имени.

### Задача 5: Окно

**Файлы:** `src/main_win32.cpp`

- [x] Две редактируемые строки, кнопки выбора через `SHBrowseForFolderW`, вычисленный итоговый путь, прогресс и статус, кнопки «Перенести» и «Отмена».
- [x] Проверка плана до запуска, подтверждение, рабочий поток, отключение отмены на критическом участке, итоговое сообщение с путями.
- **Проверка:** запуск EXE, появление окна, ручной сценарий на тестовых каталогах.

### Задача 6: Тесты и выпуск

**Файлы:** `tests/test_main.cpp`, `README.md`

- [x] Сценарии: успешный перенос и ссылка, пустая папка, совпадение имени, вложенность, отказ по reparse/жёсткой ссылке, сбой сверки, сбой ссылки, отмена, один том.
- [x] `ctest` зелёный; проверка разрядности и подсистемы EXE; README с ограничениями и инструкцией.

## Риски

| Риск | Влияние | Мера |
|---|---|---|
| Нет прав на символьную ссылку | Перенос невозможен | Проверка до копирования, предложение перезапуска от администратора |
| Обрыв питания/диска | Потеря | Устойчивая запись копии до удаления, журнал, резерв |
| Нестандартные объекты NTFS | Потеря данных | Явный отказ до копирования |
| Старые Windows не проверены фактически | Совместимость | Только совместимые API, честная пометка в README |
